Deel 1 — World fusion
World fusion and invented instruments
Bare world music flattens. Name a local genre, lock pulse and one or two signature instruments as roles, then add at most one functional second genre.
Style field stays English. Lyrics may be local-language. No artist names. No catalog titles. Do not claim sacred-ceremony authenticity; encode audible traits only.
Prompt law
ANCHOR   named local genre + region/era if it changes the sound
PULSE    meter, BPM band, clave / swing / polyrhythm / drone
ROLES    local instrument = hook or motor; second-genre tool = bed, counter, or event
VOCAL    ornament type, register, call-response, language hint
FUSION   one function only (house pulse, doom drone, trap silence, jazz harmony)
EXCLUDE  the default Suno flatteners for that region

Invented and futuristic instruments
Suno has no catalog name for things that do not exist. Encode physics, not lore.
Must state all five:
Excitation — pluck, bow, strike, breath, scrape, arc, gravity hit
Body — wood, hide, bronze, glass, ice, stone, plasma, swarm-reed
Decay — short bark, long inharmonic tail, voltage swell, reverse attack
Tuning behavior — microtonal drift, beating chorus, formant without words
Role — hook / motor / bed / counter / event
Rules:
One invented instrument per brief.
Keep one real foothold (frame drum, oud, log drum, close vocal, bowed bass).
Give it a short nonce name plus the physics sentence.
Weirdness 40–60. Variety 0. Style Influence 80–90.
Exclude orchestra default, 808, generic pad, choir wall unless that is the foothold.

Complete start briefs
Curaçao tumba-zouk (Papiamentu-ready)
Curaçao tumba fused with zouk-love, warm night-party sway, around 102 BPM, soft kick and ti-bwa woodblock.
